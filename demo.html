How to run the demo

  1. Install Rendry (free) and stay on this page.
  2. Click the Rendry icon and switch on Smart Redact.
  3. Click Capture Full Page.
  4. The editor opens with the verdict: on the free tier Rendry shows you how many sensitive items it detected; on Pro (or the 7-day free trial) every one of them is already blurred — and you can un-redact any match that shouldn't be hidden.

What just happened

Rendry reads the page the way your browser does, so Smart Redact finds real values — emails, phone numbers, card numbers, SSNs, IBANs, API keys and tokens — and blurs them exactly where they appear in the screenshot. Detection runs entirely on your device: this page, and your capture, are never uploaded anywhere.

Smart Redact is an assist, not a guarantee — it's built to catch the common patterns that slip into screenshots, and it always shows you what it found so you can review before sharing. For the full picture of what Rendry can and cannot see, read Security & Permissions.

Where this saves you time

If you attach screenshots to bug reports, support tickets, or documentation, you've probably blurred customer data by hand — box by box, screenshot by screenshot. Smart Redact does that pass for you on every capture. See how to redact a screenshot and Rendry for QA & bug reports.
